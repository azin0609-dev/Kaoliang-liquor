# 怡軒特產行｜金門高粱酒即時報價

給朋友隨時查看高粱酒價格的網頁。手機、電腦都能開，也可以「加到主畫面」當 App 用。

- 網址：https://yixuan-kinmen.github.io/
- 傳到 LINE 會自動顯示店名和預覽圖

---

## 怎麼改價格

### 方法一：Google 試算表（推薦，手機就能改）

設定一次，之後在手機的 Google 試算表 App 改數字，網頁就會自動更新（朋友開著的頁面最慢 5 分鐘、按「重新整理」馬上看到）。

**第一次設定**

1. 下載範例價格表：在 GitHub 打開 `data/prices.csv` → 右上角「下載」圖示（Download raw file）
2. 打開 [Google 試算表](https://sheets.google.com) → 「空白試算表」→ 「檔案」→「匯入」→「上傳」→ 選剛剛的 `prices.csv` → 匯入位置選「取代目前的工作表」
3. 右上角「共用」→「一般存取權」改成「知道連結的任何人」、角色「檢視者」→「複製連結」
4. 把連結交給 Claude，說「把價格來源換成這個試算表」（或自己貼到 `js/config.js` 的 `sheetUrl`）

> ⚠️ **這張試算表的內容任何人都有辦法看到**。進貨成本、客戶名單請記在另一個檔案，不要放在這張表裡。

### 方法二：直接改專案裡的 `data/prices.csv`

在 GitHub 網頁打開 `data/prices.csv` → 鉛筆圖示編輯 → 改完按「Commit changes」，約 1～2 分鐘後網頁更新。也可以直接跟 Claude 說「58度 600ml 改成 560 元」。

> 有設定 Google 試算表時，`data/prices.csv` 是備用的：Google 連不上時才會用它，並顯示「以下為備份價格」。

## 價格表欄位

第一列是欄位名稱，順序可以調換，不需要的欄可以整欄刪掉（「品名」一定要有）。

| 欄位 | 說明 | 例子 |
|---|---|---|
| 分類 | 網頁上的分組。空白會沿用上一列 | 經典系列、紀念酒、禮盒 |
| 品名 | **必填** | 金門高粱酒 |
| 度數 | 只寫數字會自動加「度」 | 58 |
| 容量 | 只寫數字會自動加「ml」 | 600ml、0.75L |
| 單瓶價 | 只寫數字。空白會顯示「請私訊詢價」 | 550 |
| 整箱價 | 可空白 | 6400 |
| 每箱瓶數 | 可空白 | 12 |
| 狀態 | 現貨／少量／缺貨／預購。寫「下架」就不顯示。空白當作現貨 | 現貨 |
| 備註 | 顯示在品名下方的小字 | 最熱銷 |
| 標籤 | 有填會在品名下方顯示 🔥 標籤，不需要就空白 | 熱賣 |
| 前次價格 | 有填會顯示漲跌（紅色 ▲ 漲、綠色 ▼ 跌），不想顯示就清空 | 530 |

名稱裡有「盒」的品項價格顯示「/盒」，其他顯示「/瓶」。

## 店家資訊、公告、聯絡按鈕

都在 `js/config.js`：

- `notice`：頁面上方的公告（例如「中秋節前訂購請提早」），不需要就改成 `''`
- `phone`：填了會出現「打電話」按鈕
- `lineUrl`：填了會出現「LINE 詢問」按鈕（LINE →「加入好友」→「行動條碼」→ 我的行動條碼下方「複製連結」）
- `contactNote`：聯絡按鈕上方的提醒文字

## 第一次開通網站

1. 把這個分支的修改合併到 `main`（在 GitHub 的 Pull request 按「Merge」）
2. 儲存庫 →「Settings」→ 左邊「Pages」→「Branch」選 `main`、資料夾 `/ (root)` →「Save」
3. 約 1～2 分鐘後打開 https://yixuan-kinmen.github.io/

## 本機預覽（改版前先看看）

雙擊 `start.bat` → 自動打開 `http://localhost:8001`。
自動檢查：`http://localhost:8001/tests/tests.html`。

## 酒類規定提醒

- 頁面上的「禁止酒駕　飲酒過量，有害健康」和「未滿十八歲禁止飲酒」請保留：菸酒管理法要求酒的廣告要明顯標示警語
- 網頁只報價、不做線上下單或付款：菸酒管理法不允許用網路購物這類無法當面確認年齡的方式賣酒，交易請私下確認
- 第一次進入會詢問是否滿 18 歲
- 以上只是一般提醒，不是法律意見；有疑問請以主管機關（財政部國庫署）公告為準
